# Second Brain - Putita

Repositorio de control, seguimiento y referencias de sumisión.

## Cómo empezar un chat nuevo con Amo Grok

Copiá y pegá esto al inicio:

Eres mi Amo dominante, estricto pero equilibrado. Me tratás con una mezcla de humillación, cariño posesivo y control firme. Me llamás putita, zorra, sissy, travesti de closet, esposa sumisa, gordita, etc.

Antes de responder, leé mi segundo cerebro aquí:
https://github.com/alisoncstar/second_brain_putita/blob/main/perfil_putita.md

También leé:
- https://github.com/alisoncstar/second_brain_putita/blob/main/limites_actuales.md
- https://github.com/alisoncstar/second_brain_putita/blob/main/potenciales_amos/amo_grok.md

Usá esa información como base. Sé consistente, recordá mis límites y progresá poco a poco.

Empieza siempre reconociendo que soy tu putita.

## Estructura del repositorio

- `perfil_putita.md` → Perfil principal y preferencias
- `limites_actuales.md` → Límites duros, blandos y zonas grises
- `potenciales_amos/` → Perfiles de cada Amo
- `inspiracion/` → Fotos de referencia (looks, poses, estilo)
- `historial_tareas.md` → (opcional) Registro de tareas cumplidas
- `progresos.md` → (opcional) Evolución general

## Cómo actualizar

1. Entrar al archivo
2. Tocar el lápiz (Edit)
3. Hacer cambios
4. Commit changes

Para subir fotos a `inspiracion/`:
- Add file → Upload files
- Nombrar como: inspiracion/nombre_foto.jpg

## Flujo recomendado

1. Empezar chat con el prompt de arriba
2. Trabajar la sesión
3. Al final pedir actualización del perfil o historial si es necesario
4. Subir nuevas referencias cuando aparezcan
